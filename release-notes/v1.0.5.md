# ZMK Studio Custom v1.0.5

v1.0.5 fixes backup export compatibility with firmware builds that do not expose the optional custom-behavior RPC.

## What's fixed

- Backup export now correctly recognizes the ZMK RPC `NOT_FOUND` response using its numeric error condition.
- When the optional custom-behavior RPC is unsupported, export continues with the supported keymap and combo data instead of failing with a Meta error.
- Other RPC errors are still treated as real failures; the fallback is limited to the unsupported-RPC condition.

## Compatibility

This is a Studio frontend and desktop-app compatibility fix.

- No keyboard firmware changes are required.
- Existing keymaps and live keyboard configuration are not modified by exporting a backup.
- The hosted web app receives the fix through the successful deployment.
- The desktop installers bundle the same updated Studio frontend.
- Import behavior is unchanged; this release does not automatically import or alter any keymap.

## Desktop downloads

This release build produces installers for:

- **Windows:** EXE and MSI
- **macOS:** universal DMG and updater app archive
- **Linux x86_64:** AppImage and DEB
- **Linux ARM64:** AppImage and DEB

Windows installers are unsigned in the current build configuration, so Windows may show an Unknown Publisher or SmartScreen warning.
