# ZMK Studio Custom v1.0.4

v1.0.4 is a focused compatibility fix for mouse behavior visualization in the custom keymap editor.

## What's fixed

- Mouse move and mouse scroll key bindings now resolve their Studio icons when behavior metadata uses underscores, hyphens, or spaces.
- Behavior names are normalized before the renderer selects the corresponding visual treatment.

## Compatibility

This is a frontend and desktop-app rendering fix only.

- No keyboard firmware changes are required.
- Existing keymaps, saved configurations, Studio RPC communication, and mouse functionality are unchanged.
- The web app receives the fix through the hosted deployment.
- Windows and macOS desktop users should install the v1.0.4 build to receive the updated bundled frontend.

## Downloads

Windows and macOS installers will be attached to this release after the release build completes.
